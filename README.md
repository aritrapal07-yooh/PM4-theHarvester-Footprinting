# W2-PM4 – theHarvester Footprinting

**Project:** Passive OSINT Demonstration

**Tool:** theHarvester 4.11.1

**Platform:** Kali Linux

**Target:** example.com (reserved demonstration domain)

### Objective
To understand passive reconnaissance and demonstrate theHarvester for collecting publicly available domain-related information.

### Methodology
1. Installed and verified theHarvester.
2. Reviewed the available source options.
3. Selected crtsh and certspotter.
4. Performed a demonstration scan.
5. Saved the output in supported report formats.
6. Reviewed source execution status and findings.

### Results
The tool executed the selected information sources. The actual number of findings and source outcomes are documented using the generated output files.

### Learning Outcomes
- Understood OSINT fundamentals.
- Learned passive reconnaissance.
- Practised theHarvester command-line interface.
- Learned how to save and analyse scan results.
- Understood the importance of authorized security assessments.

### Conclusion
This practical provided introductory experience with theHarvester and demonstrated how publicly available information can be reviewed during cybersecurity reconnaissance.

**Scope limitation:** example.com was used only as a reserved demonstration domain. This practical does not represent an assessment of a real organization's infrastructure.
